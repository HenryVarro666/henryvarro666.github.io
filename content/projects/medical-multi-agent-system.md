Python research prototype using LangGraph and FastAPI for intake, diagnosis, treatment, coding, and a deterministic audit. Extends an open-source scaffold with symptom-based retrieval, curated drug-interaction and allergy checks, bounded diagnosis retries, and a configurable OpenAI-compatible model backend. Includes offline regression tests and an evaluation harness with five synthetic cases and archived stage outputs.
