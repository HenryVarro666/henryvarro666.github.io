这篇写给第一次拿到 PS5 精英手柄（官方名叫 DualSense Edge 无线控制器）的人。从头读下来，你能把手柄连上主机、认全按键、回到主页，再用上它比普通 PS5 手柄多出来的东西：可换的摇杆帽和背面键、可调的扳机键程、用 Fn 键切换的配置文件。

文中的操作步骤都对照索尼 PlayStation 官网的简体中文支持页，引号里是官方原话，链接放在每一节开头和文末，核对日期是 2026-11-27。主机系统更新后菜单名可能会变，以你屏幕上显示的为准。

## 1. 盒子里有什么 {#in-the-box}

[DualSense Edge 产品页](https://www.playstation.com/zh-hans-cn/accessories/dualsense-edge-wireless-controller/)列出的配件：

| 配件 | 数量 | 用途 |
|---|---|---|
| DualSense Edge 无线控制器 | 1 | 手柄本体 |
| USB 编织连接线 | 1 | 连主机、充电 |
| 操作杆帽：标准、高圆顶、低圆顶 | 各 2 | 按手感换着用，见[第 6 节](#parts) |
| 半圆顶型背面键 | 2 | 装在手柄背面，见[第 6 节](#parts) |
| 控制杆背面键 | 2 | 同上，左右各一，不能互换（产品页叫“杠杆式背面键”） |
| 接口外壳 | 1 | 套在线的接头上，防止线被意外扯掉 |
| 便携收纳盒 | 1 | 装手柄和配件，放在盒里也能充电 |

## 2. 认识按键 {#buttons}

![DualSense Edge 正面示意图：PS 键在触摸板下方、两个摇杆中间；创建键和选项键在触摸板两侧；方向键在左，动作键在右；两个 Fn 键在摇杆下方。](front.svg "图 1：正面。高亮的是 PS 键；虚线框是背面键，从正面看不到。")

“官方说明”一栏出自[PS5 按键功能](https://www.playstation.com/zh-hans-hk/support/hardware/ps5-button-functions/)，Fn 键一行出自[配置文件设置页](https://www.playstation.com/zh-hans-cn/support/hardware/set-up-edge-controller/)。

| 按键 | 官方说明 | 新手怎么理解 |
|---|---|---|
| PS 键 | 按下一次可访问控制中心；按住可转到主画面 | 回主页就靠它 |
| 交叉键 ✕ | 选择突出显示的项目 | “确定” |
| 圆圈键 ○ | 取消命令 | “返回” |
| 方向键 | 突出显示屏幕上的项目 | 移动光标，左摇杆也能移 |
| 选项键 | 显示选项菜单 | 关游戏时会用到 |
| 创建键 | 显示创建菜单并拍摄截屏及短片 | 截图和录屏 |
| 静音键 | 将控制器麦克风和喇叭静音 | PS 键下面那个小长条 |
| 触摸板 | 用于游戏功能 | 平时用不上 |
| Fn 键（精英手柄独有） | 按住 Fn 键再按动作键切换配置文件；按住 Fn 键再按选项键回到自定义菜单 | 回主页用不到，别和 PS 键弄混，见[第 7 节](#profiles) |

索尼文档里的“主画面”就是平时说的主页，下文两个词混用。

![DualSense Edge 背面示意图：两个背面键在握把背面，L2 和 R2 键程滑杆在扳机下方的背面。](back.svg "图 2：背面。从背面看，左右和正面相反。")

背面还有两样图里没画的东西：RELEASE 锁扣，换操作杆模块时用（[第 9 节](#stick-module)）；再启动键小孔，重设手柄时用（[第 11 节](#troubleshoot)）。官方页只说它们在背面，没给具体位置，拿手柄翻过来找一下就能看到。

## 3. 第一次连接主机 {#connect}

步骤出自[如何连接 DualSense Edge 无线控制器](https://www.playstation.com/zh-hans-cn/support/hardware/pair-edge-controller/)：

1. 打开 PS5 主机。
2. 用随附的 USB 连接线把手柄连到主机。
3. 按下 PS 键，手柄开机。光条闪烁后，玩家指示灯亮起，就连好了。

电量充足后可以拔掉线，无线使用。最多可以同时用四个手柄，按下 PS 键时主机会给每个玩家分配一种颜色。

**装接口外壳。** 官方的说法是“为了确保连接线不会意外断开，请安装接口外壳”：

1. 滑动接口外壳上的锁扣，把外壳打开。
2. 把 USB Type-C 接口放进接口外壳，盖上外壳盖。
3. 确认 USB Type-C 接口的位置正确。

## 4. 充电 {#charge}

- 主机开机或待机时，用随附的 USB 编织连接线把手柄连到主机，就会充电。
- 主机在待机模式时，光条会呈橙色缓慢闪烁；充完电，光条熄灭。
- 也可以用 USB 线连电脑或其他 USB 设备充电。线要符合 USB 标准；官方说有些设备可能充不了。
- 手柄放在便携收纳盒里也能充电：打开收纳盒背面的翻盖，就能找到 USB 端口。
- 想看剩多少电：按一下 PS 键打开控制中心，选「周边设备」。

## 5. 回到主页、控制中心和关游戏 {#home}

按住 PS 键回主页，按一下 PS 键打开控制中心。

![从游戏回到主画面的两条路：按住 PS 键直接回去；或者按一下 PS 键打开控制中心，选「主页」再按交叉键。](home-flow.svg "图 3：回主画面的两条路。虚线是从主画面回到刚才的游戏。")

**方法一：按住 PS 键。** 在游戏或应用里按住 PS 键，画面跳到主画面后松手。

**方法二：从控制中心进。**

1. 按一下 PS 键，屏幕下方出现一排图标，这就是控制中心。
2. 用方向键或左摇杆移到「主页」。
3. 按交叉键 ✕，回到主画面。不想去了，按圆圈键 ○ 取消。

**回到刚才的游戏。** 回主页不会关掉游戏，官方原话是“显示主画面时，有些游戏和应用程序会暂停”。在主画面选中那个游戏，按 ✕ 就接着玩。

**彻底关掉游戏。** 按一下 PS 键，选「切换器」，选中要关的游戏，按选项键，在弹出的菜单里选关闭。官方页只写了切换器可以“关闭正在玩的游戏”，菜单里的具体字样以屏幕为准。没存档的游戏关掉会丢进度，先存档再关。

控制中心各图标的作用，按[自定义 PS5 控制中心](https://www.playstation.com/zh-hans-cn/support/games/customize-ps5-control-center)列出的顺序。图标可以自己挪位置，所以你屏幕上的顺序可能不一样：

| 图标 | 官方说明 |
|---|---|
| 主页 | 显示主画面 |
| 切换器 | 显示最近启动的游戏和应用程序。在游戏和应用程序之间切换，或关闭正在玩的游戏 |
| 通知 | 查看收到的通知 |
| Game Base | 查看朋友的活动、发送消息或语音聊天，与朋友保持联系 |
| 音乐 | 在玩游戏的同时听音乐 |
| 声音 | 管理声音设置 |
| 麦克风 | 更改输入设备，静音或取消静音麦克风，调整麦克风音量 |
| 周边设备 | 查看控制器或耳机组电池电量，更改设置 |
| 个人简介 | 更新在线状态，访问个人简介，查看奖杯，切换用户，退出登录 |
| 电源 | 关闭 PS5 主机或将其置于待机模式 |

## 6. 换摇杆帽、装背面键、调扳机键程 {#parts}

步骤出自[如何个性化设置 DualSense Edge 无线控制器](https://www.playstation.com/zh-hans-cn/support/hardware/personalize-edge-controller/)。

**换摇杆帽**（标准、高圆顶、低圆顶三种）：

1. 把装在手柄上的操作杆帽向上拉起，帽子就掀开了。
2. 把选好的操作杆帽对准操作杆，向下按压，确保固定。

**装背面键：**

- 半圆顶型背面键左右可以互换，直接插进背面键槽。
- 控制杆背面键左右不能互换。装之前看背面键上印的是 R（右）还是 L（左），插进对应的背面键槽。
- 取下时，把背面键拉向手柄顶部，再从槽里提起来。

背面键按下去起什么作用，要在配置文件的按键配置里分配，见[第 7 节](#profiles)。

**调 L2/R2 键程：** 手柄背面的 L2 和 R2 键程滑杆有长行程、中行程、短行程三档。官方提醒：“如果将键程滑杆设定为中行程或短行程，扳机效果功能将不起作用。”扳机效果就是有些游戏里扳机按下去会有阻力，想保留这种手感就用长行程。

## 7. 配置文件和 Fn 键 {#profiles}

配置文件是一整套按键和手感设置。你可以存几套，玩不同游戏时用 Fn 键快速切换。步骤出自[在 PS5 主机上设置 DualSense Edge 配置文件](https://www.playstation.com/zh-hans-cn/support/hardware/set-up-edge-controller/)。

![按住 Fn 键再按三角键换回默认配置文件；再按圆圈键、交叉键或正方键，换成分配给它的配置文件。](profiles.svg "图 4：Fn 键快捷方式。Fn + 三角键固定是默认配置文件。")

**新建配置文件：**

1. 前往「设定」>「周边设备」。
2. 选择「DualSense Edge 无线控制器」>「自定义配置文件」。
3. 选择「创建自定义配置文件」，输入名称，然后选择「确定」。
4. 选择要自定义的项目：按键配置、操作杆灵敏度/盲区、扳机盲区、震动强度、扳机效果强度。

**分配到 Fn 快捷方式：**

1. 前往「设定」>「周边设备」。
2. 选择「DualSense Edge 无线控制器」>「自定义配置文件」。
3. 到「未分配的配置文件」选项卡，选择要分配的配置文件旁边的「分配」。
4. 选择快捷方式。这个快捷方式原来有配置文件的话，新分配的会把它覆盖。

**切换：** 游戏中按住 Fn 键，再按三角键、圆圈键、交叉键或正方键。官方说“分配给Fn键和三角键快捷方式的配置文件是默认配置文件，无法更改”，所以按键突然乱了，按住 Fn 键再按三角键，就回到默认设置。

**游戏中途再调：** 按住 Fn 键再按选项键，回到自定义菜单。

几条限制：

- Fn 键本身不能改成别的功能，别的键也不能当 Fn 键用。
- L2 和 R2 可以互换，但不能把别的键分配成扳机键。
- 手柄上最多存四套配置文件，包括默认的一套；最多三套能分配到快捷方式。这条写在[电脑上设置配置文件](https://www.playstation.com/zh-hans-cn/support/hardware/set-up-edge-pc/)那一页。

## 8. 更新手柄软件 {#update}

在 PS5 上（出自[连接页](https://www.playstation.com/zh-hans-cn/support/hardware/pair-edge-controller/)的更新一节）：

1. 前往「设定」>「周边设备」>「DualSense Edge 无线控制器」。
2. 选择「DualSense Edge 无线控制器设备软件」，更新手柄软件。

官方建议主机系统软件和手柄设备软件都保持最新版本。

在 Windows 电脑上：装 PlayStation Accessories 应用，打开「控制器固件」，有新版本时会显示「升级」。官方提醒更新期间不要关电脑，也不要断开手柄。

## 9. 摇杆坏了：换操作杆模块 {#stick-module}

操作杆失灵或不能用时，可以只换操作杆模块。新模块单独出售，左右通用，装在哪一侧都行。步骤出自[如何更换操作杆模块](https://www.playstation.com/zh-hans-cn/support/hardware/edge-replace-stick/)：

1. 确认手柄上的玩家指示灯已经熄灭。没熄灭就长按 PS 键，直到熄灭。
2. 拔掉手柄上的 USB 连接线。
3. 滑动手柄背面的 RELEASE 锁扣，取下前盖。
4. 提起释放杆。
5. 取下旧模块，装上新模块。确认位置正确后，沿凹槽滑动模块，直到听到“咔嗒”一声。
6. 拉低释放杆。
7. 装回前盖：前盖的凸起部分对准手柄上的槽口，小心推入，直到听到“咔嗒”一声。

## 10. 连电脑或手机 {#other-devices}

步骤出自[DualSense Edge 与 Windows、Mac、Android 和 iOS 设备搭配使用](https://www.playstation.com/zh-hans-cn/support/hardware/dualsense-edge-other-devices/)。官方列出的系统有 Windows 10（64 位）、Windows 11，以及 macOS、iOS、iPadOS、tvOS 的较新版本，具体版本号看那一页。

1. 确认光条和玩家指示灯都已熄灭。亮着的话，按住 PS 键直到熄灭。
2. 按住创建键的同时，按住 PS 键，直到光条闪烁。
3. 在设备上打开蓝牙，添加蓝牙设备，在列表里选手柄。
4. 配对完成后，光条闪烁，然后玩家指示灯亮起。

在电脑上，Fn 键只能切换已经存在手柄里的配置文件。想换回 PS5 上用，又连不上的话，用 USB 线连主机再按 PS 键，也就是[第 3 节](#connect)的步骤。

{{< details summary="进阶：一个手柄记住多台设备" >}}
官方说“一个控制器最多可以注册四个不同的配对，每个配对都会被分配一个槽位”。四个槽位对应四个动作键：三角键是 1，圆圈键是 2，交叉键是 3，正方键是 4。

- 配对到指定槽位：同时按住那个动作键和 PS 键超过 5 秒，再按上面的第 3、4 步完成配对。
- 在已配对的设备之间切换：按住对应的动作键和 PS 键约 3 秒。

## 11. 出问题时 {#troubleshoot}

**按 PS 键没反应。** 可能是没电了。用 USB 线连主机充一会儿，再按 PS 键。

**按键和平时不一样。** 可能误碰 Fn 键切换了配置文件，按住 Fn 键再按三角键回到默认。官方还提醒，游戏里自己的控制器设定可能和配置文件冲突，也去游戏设置里看一下。

**重设手柄。** 步骤出自[如何排查 DualSense Edge 无线控制器问题](https://www.playstation.com/zh-hans-cn/support/hardware/edge-troubleshoot/)：

1. 关闭 PS5 主机。
2. 拔掉手柄上的 USB 连接线。
3. 找到手柄背面的小孔，里面是再启动键，用大头针之类的东西按下去。官方页没写要按多久。
4. 用随附的 USB 连接线把手柄连到主机，按 PS 键。

官方说这种重设“不会重新配置您的控制器，也不会影响配对操作和配置文件设定”，可以放心按。电脑上 PlayStation Accessories 里也有一个「重设 DualSense Edge 无线控制器」，那个是恢复出厂设置，官方原话是“您的所有配置文件都将被删除”。只是想让手柄恢复反应，用背面小孔那种。

**还是不行。** 先把主机系统软件和手柄设备软件都更新到最新（[第 8 节](#update)），再不行就走[索尼维修服务](https://playstation.com/repairs)。
