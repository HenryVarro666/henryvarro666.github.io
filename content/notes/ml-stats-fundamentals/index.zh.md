## 概率 {#probability}

**写出贝叶斯公式。先验什么时候最要紧？** $P(A \mid B) = P(B \mid A)\,P(A) / P(B)$。事件越罕见，先验越要紧。基率 0.1% 时，一个 recall 90%、假阳性率 1% 的检测器，后验概率也只有 8% 左右。练习题里[算过这个数](/zh/notes/fraud-detection-practice/#drill-bayes)。

**独立和条件独立有什么区别？** $P(A \cap B) = P(A)\,P(B)$ 时 $A$ 和 $B$ 独立。在 $C$ 的每个取值之内这个等式都成立，就是给定 $C$ 条件独立。两者互不蕴含。有共同原因的两个症状，整体上相关，给定原因后独立。两个相互独立的原因，一旦以它们共同的结果为条件，就变得相关。

**期望和方差最常用的规则是哪几条？** 期望是线性的，不需要独立：$E[aX + bY] = aE[X] + bE[Y]$。方差不是：$\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y) + 2\,\mathrm{Cov}(X, Y)$，$\mathrm{Var}(aX) = a^2\,\mathrm{Var}(X)$。协方差那一项解释了为什么对相关的模型取平均，效果不如对独立的模型取平均。

**哪些分布应该一眼认出来？**

| 分布 | 描述什么 | 均值和方差 |
|---|---|---|
| 二项分布 | $n$ 笔交易里的欺诈笔数 | $np$ 和 $np(1-p)$ |
| 泊松分布 | 固定时间段内的事件数，比如每小时报警数 | $\lambda$ 和 $\lambda$ |
| 几何分布 | 出现第一笔欺诈之前的交易笔数 | $1/p$ 和 $(1-p)/p^2$ |
| 指数分布 | 两次事件之间的时间 | $1/\lambda$ 和 $1/\lambda^2$ |
| 正态分布 | 许多小影响的和或平均 | $\mu$ 和 $\sigma^2$ |
| 对数正态分布 | 金额这类取正值、右偏的量 | 取对数后服从正态 |

**大数定律和中心极限定理有什么区别？** 大数定律说样本均值收敛到真实均值。中心极限定理说得更多：只要方差有限，不管数据是什么形状，样本均值的分布都趋近正态，标准差是 $\sigma/\sqrt{n}$。均值和比例的 z 区间靠的就是它。标准差 \$80、400 笔交易时，均值的误差大约是 \$4。重尾分布和罕见事件下，收敛很慢。

**泊松近似什么时候有用？** $n$ 很大、$p$ 很小的二项分布，接近均值为 $np$ 的泊松分布。10,000 笔交易、欺诈率 0.1% 时，均值是 10，标准差是 3.2。一笔欺诈都没有的概率是 0.00005，出现 20 笔以上的概率是 0.35%。所以笔数翻倍是信号，不是噪声。

**1,000 笔交易里一笔欺诈都没看到，对欺诈率能说什么？** 不能说它是零。解 $(1 - p)^n = 0.05$，得到 95% 置信上界约为 $3/n$，这里是 0.3%。这叫“三法则”（rule of three）。

**决策里怎么用期望值？** 对每个动作，把各种结果的概率乘以收益再加总，选总和最好的那个。在欺诈里，它把一个概率和两个成本变成一个阈值，练习题里[有推导](/zh/notes/fraud-detection-practice/#drill-cost)。

## 估计和区间 {#estimation}

**什么是最大似然估计？** 选一组参数，使观测到的数据出现的概率最大。对一个比率，它就是 $k/n$。在正则条件下，估计量是相合的、渐近正态的，标准误就是从这里来的。逻辑回归和大多数神经网络都是这样拟合的：最小化 log loss 就是最大化似然。

**最大似然和最大后验有什么区别？** 最大后验（maximum a posteriori，MAP）最大化的是似然乘以先验。给权重加高斯先验得到 L2 惩罚，拉普拉斯先验得到 L1，见[正则那一题](/zh/notes/fraud-detection-practice/#regularization)。数据足够多时，两者一致。

**估计量的偏差和方差是什么？** 偏差是估计的期望减去真值，方差是估计在不同样本之间的波动。均方误差等于偏差的平方加方差。样本方差除以 $n - 1$，就是为了消掉偏差。有偏的估计量误差反而可能更小，收缩估计就是这样。

**样本很少时估出来的比率，为什么要收缩？** 一家商户 50 笔交易里有 2 笔欺诈，原始比率是 4%。用 Beta(1, 999) 作先验，它的均值是整体欺诈率 0.1%，后验均值是 0.29%。另一家商户 5,000 笔里有 200 笔，同样是 4%，后验均值只降到 3.35%。小样本被拉向先验，大样本基本不动。带平滑的 target encoding 是同一个思路。

**标准差和标准误有什么区别？** 标准差描述数据本身的离散程度。标准误描述一个估计值的波动；对均值来说，它是标准差除以 $\sqrt{n}$。数据量变成四倍，标准误减半。

**95% 置信区间是什么意思？** 构造这个区间的方法，在反复抽样时有 95% 的次数会覆盖真值。它不是说“参数有 95% 的概率落在这个具体的区间里”。那句话属于贝叶斯的可信区间，需要先验。

**很小的比例用哪种区间？** Wald 区间 $\hat{p} \pm 1.96\,SE$ 在计数很小时会失效。2,000 笔里 3 笔欺诈，它给出 −0.02% 到 0.32%，下界是负的。Wilson 区间给出 0.05% 到 0.44%。罕见事件我用 Wilson，[Brown、Cai 和 DasGupta](https://doi.org/10.1214/ss/1009213286) 对小样本也是这样建议的。

**什么时候用 bootstrap？** 指标的标准误没有简单公式的时候：PR-AUC、固定报警率下的 recall、两个中位数的比值。做法是有放回地重抽样，重算指标，取分位数。重抽样的单位必须是相互独立的那一层，是账户而不是交易，否则区间会偏窄。recall 为 320/400 时，bootstrap 给出 0.757 到 0.838，公式给出 0.761 到 0.839。

**频率学派和贝叶斯学派有什么区别？** 频率学派把参数看成固定的、数据是随机的，结论描述的是一个方法在反复抽样下的表现。贝叶斯学派给参数一个分布，用数据更新它，可以直接做概率陈述，代价是要选先验。实际工作里，小样本的比率我用收缩估计，实验用频率学派的检验。

## 假设检验 {#testing}

**p 值是什么？** 在原假设为真的前提下，得到至少和观测结果一样极端的结果的概率。它不是原假设为真的概率，也不说明效应有多大。

**第一类错误、第二类错误和功效是什么？** 第一类错误是拒绝了为真的原假设，概率是 $\alpha$。第二类错误是漏掉了真实存在的效应，概率是 $\beta$。功效（power）是 $1 - \beta$。样本量固定时，压低一种错误就会抬高另一种，和移动欺诈阈值完全一样。

**检验需要的样本量由什么决定？** 效应大小、方差、$\alpha$ 和功效。比较两个比例时，每组需要的样本量是：

$$
n \approx \frac{(z_{\alpha/2} + z_{\beta})^2\,\bigl[p_1(1-p_1) + p_2(1-p_2)\bigr]}{(p_1 - p_2)^2}
$$

$\alpha = 5\%$、功效 80% 时，要检测出从 10% 到 12% 的变化，每组需要 3,839 个样本。效应减半，样本量变成四倍。[A/B 测试那篇](/zh/notes/ab-testing/#power)讲得更细。

**结果显著了，它是真的概率有多大？** 取决于被检验的想法里有多少是真的，就像 precision 取决于基率。如果我检验的想法有 10% 是真的，功效 80%，$\alpha = 5\%$，那么显著的结果里有 64% 是真的。

**z 检验、t 检验和 Welch 检验怎么选？** 方差已知或样本很大时用 z 检验，比如比例。方差靠估计、样本又小的均值用 t 检验，它的尾部更厚。Welch 版本不假设两组方差相等，是两组比较时稳妥的默认选择。同一批对象测两次时用配对 t 检验：它检验的是差值，去掉了个体之间的差异。

**卡方检验是干什么的？** 比较观测到的计数和某个假设下的期望计数。最常见的用法是列联表的独立性检验，比如各渠道的欺诈率是否相同。每个格子的期望计数要在 5 左右或更多，不够时用 Fisher 精确检验。

**哪些检验不假设特定的分布？** Mann-Whitney 检验问的是一组的取值是否倾向于比另一组大，它的统计量[换个名字就是 AUC](/zh/notes/fraud-detection-practice/#drill-auc)。Kolmogorov-Smirnov 检验衡量两个累积分布之间的最大差距，所以对任何形状上的差异都有反应。置换检验把组别标签打乱，重新计算我选定的任意统计量；它只要求原假设下标签可以互换。

**你一次做 20 个检验，有什么变化？** 每个都用 5% 时，至少出现一个假阳性的概率是 64%。Bonferroni 控制的是“出现任何假阳性”的概率：每个检验用 $\alpha/m$，这里是 0.0025，比较保守。[Benjamini-Hochberg](https://doi.org/10.1111/j.2517-6161.1995.tb02031.x) 控制的是被拒绝的假设里假阳性的期望比例：把 p 值排序，找到满足 $p_{(k)} \le (k/m)\,q$ 的最大名次 $k$，拒绝前 $k$ 个。脚本里的十个 p 值，Bonferroni 拒绝 1 个，Benjamini-Hochberg 拒绝 3 个。任何一个假阳性代价都很高时用前者，筛选大量特征时用后者。

**实验进行中反复偷看结果，有什么问题？** 每看一次，就多一次越过阈值的机会，所以“一显著就停”会把假阳性率抬到远高于 $\alpha$。要么事先定好样本量，要么用序贯设计，把 $\alpha$ 分摊到每次查看上。A/B 测试那篇有[专门讲停止规则的一节](/zh/notes/ab-testing/#stopping)。

**统计显著和实际显著有什么区别？** 数据有几百万行时，微不足道的差异也会显著。我会报效应大小和它的区间，并拿它和“能改变决策的最小效应”比较。

**单侧还是双侧检验？** 默认双侧。只有当相反方向的结果和“没有效应”会导致同样的动作，并且这一点在看数据之前就定好了，才用单侧。

## 回归 {#regression}

**普通最小二乘有哪些假设？** 它最小化残差平方和，解是 $\hat{\beta} = (X^\top X)^{-1} X^\top y$。要让系数无偏，需要模型对参数是线性的、给定特征时误差均值为零、没有完全共线。要让标准误有效，还需要误差相互独立、方差恒定。误差服从正态只在小样本做推断时才要紧。

**系数怎么解读？** 其他特征保持不变时，这个特征增加一个单位，结果的期望变化量。结果取了对数时，它近似是百分比变化。特征之间相关时，“其他保持不变”描述的情形可能根本不会出现。

**多重共线性会造成什么？** 预测不受影响。单个系数变得不稳定，标准误很大，符号可能翻转。用方差膨胀因子 $1/(1 - R_j^2)$ 衡量，超过 5 到 10 就要留意。办法是删掉或合并特征，或者用岭回归。

**什么是异方差，要紧吗？** 误差的方差随特征变化：金额越大，误差越大。系数仍然无偏，但标准误是错的。可以用稳健标准误，对结果取对数建模，或者给观测加权。

**R 方有什么问题？** 它是被解释的方差占比，加特征时只增不减。所以要用调整后的 R 方，更好的是看留出数据上的误差。R 方高不说明模型是对的，R 方低的模型也可能有用。

**解释一下逻辑回归。** 它把 log-odds 建模成特征的线性函数：$\log\frac{p}{1-p} = \beta_0 + \beta^\top x$。用最大似然拟合，等价于最小化 log loss。问题是凸的，没有闭式解，所以用迭代求解。决策边界是线性的。$e^{\beta}$ 是 odds ratio：系数 0.7 让 odds 翻倍，1% 的概率因此变成 1.99%。

**二分类目标为什么不用线性回归？** 预测值会跑出 0 到 1 的范围，误差的方差不恒定，平方损失还会把“很有把握的正确预测”当成误差来惩罚。log loss 才和“是或否”这类结果的似然对得上。

**什么是遗漏变量偏差？** 一个同时影响某个特征和结果的变量没有放进模型，它的影响就被这个特征的系数吸收了。只做预测、关系又稳定时没有问题；要做因果解读时是致命的。[因果推断那篇](/zh/notes/causal-inference/#dag)画了各种情形。

**什么是辛普森悖论？** 在每个子组里都成立的规律，合起来却反过来，原因是各子组的规模不同。规则 B 在 web 报警上比规则 A 更准（95% 对 90%），在 mobile 报警上也更准（40% 对 30%）。合起来看，A 是 84.5%，B 是 45.0%，因为 A 的报警大多在 web，B 的大多在 mobile。我会在分群内部比较，或者按同一种构成重新加权。因果推断那篇有[另一个例子](/zh/notes/causal-inference/#simpson)。

**Pearson 相关和 Spearman 相关有什么区别？** Pearson 衡量线性相关，对离群值敏感。Spearman 是在秩上算的 Pearson，所以衡量的是任何单调关系，也更稳健。相关系数为零不等于独立。

## 抽样、偏差和分布变化 {#sampling}

**有哪些抽样方式值得知道？** 简单随机抽样。分层抽样在各组内部抽，保证稀有的组被抽到，方差也更低。整群抽样一次抽一整组，更便宜，噪声更大。加权抽样对稀有类别多抽，再用权重还原；练习题里有[还原的公式](/zh/notes/fraud-detection-practice/#drill-downsampling)。

**选择偏差和幸存者偏差是什么？** 选择偏差：样本是由一个和结果有关的过程选出来的，比如只有被放行的交易才有标签。幸存者偏差：只有通过了某道筛选的个案留了下来，比如从未被关闭的账户。两种情况下，样本都不再代表模型将来要评分的人群。欺诈标签[两个问题都有](/zh/notes/fraud-detection-practice/#labels)。

**为什么按客户切分，而不按行切分？** 同一个客户的各行是相关的。如果它们同时出现在切分的两边，模型等于在它见过一部分的数据上被测试。我按实体切分；数据有时间顺序时，还要按时间切分。

**混杂因子、中介变量和对撞因子是什么？** 混杂因子同时影响特征和结果：要调整它。中介变量在特征到结果的路径上：调整它会去掉一部分效应。对撞因子同时被两者影响：调整它会造出本不存在的关联。选择偏差就是对撞偏差。

**协变量偏移、标签偏移和概念漂移有什么区别？** 协变量偏移：输入的分布变了，输入和结果的关系没变，所以重新加权或重训。标签偏移：基率变了，每个类别内部长得一样，所以按新的基率调整预测概率，用的是和还原降采样相同的 odds 校正。概念漂移：关系本身变了，比如欺诈者换了手法，只有新标签能解决。练习题里讲了[怎么应对](/zh/notes/fraud-detection-practice/#drift)。

**完全随机缺失、随机缺失和非随机缺失是什么？** 完全随机缺失：缺失和任何东西都无关，删掉这些行是无偏的，只是浪费数据。随机缺失：缺失取决于已观测到的变量，所以用它们来插补。非随机缺失：缺失取决于缺掉的那个值本身，比如收入低的人不填收入，光靠数据解决不了。做预测时，“这个值缺失了”的指示变量往往是有用的特征，树模型也能直接处理缺失值。插补只在训练数据上拟合。

## 模型评估 {#evaluation}

**precision、recall、specificity 和 F1 怎么定义？** precision 是 $TP/(TP+FP)$。recall 也叫 sensitivity，是 $TP/(TP+FN)$。specificity 是 $TN/(TN+FP)$，等于 1 减假阳性率。F1 是 precision 和 recall 的调和平均，$F_\beta$ 把 recall 的权重放大到 $\beta$ 倍。[precision 和 recall 那篇](/zh/notes/precision-vs-recall/)画了两者的取舍。

**ROC-AUC 还是 PR-AUC？** ROC-AUC 不随类别比例变化；比较排序时这是优点，正样本很少时这是缺点。precision-recall 曲线展示的是报警队列实际会是什么样子。[另一篇笔记](/zh/notes/roc-auc-vs-pr-auc/)专门比较了两者。

**信用评分里的 KS 和 Gini 是什么？** KS 是好账户和坏账户的累积分数分布之间的最大差距，等于“真阳性率减假阳性率”的最大值。Gini 是 $2 \times \mathrm{AUC} - 1$。两组分数分别服从 N(0, 1) 和 N(1, 1) 时，AUC 是 0.760，Gini 是 0.520，KS 是 0.383。KS 描述的是一个阈值，AUC 和 Gini 描述的是整个排序。

**lift 和捕获率是什么？** 捕获率（capture rate）是分数最高的 $x\%$ 里包含了全部正样本的多大比例。lift 是这个比例除以 $x$，也就是比随机好多少倍。如果分数最高的 1% 里有 50% 的欺诈，lift 就是 50。

**log loss 和 Brier score 有什么区别？** 两者都是 proper scoring rule：真实概率能让它们取到最小，所以它们同时奖励校准和排序。log loss 对很有把握的错误的惩罚没有上限。Brier score 是概率的均方误差，有上界。四个样本里有一个正样本时，一个给出 0.7、0.2、0.1、0.1 的模型，Brier 是 0.0375，log loss 是 0.198。四个都说 0.25，则是 0.1875 和 0.562。

**校准和区分度有什么区别？** 区分度（discrimination）是把正样本排在负样本前面的能力，用 AUC 衡量。校准（calibration）是预测 10% 的事情是否真的有 10% 发生。对分数做任何单调变换，都会改变校准，但不改变 AUC。分数要进入成本计算时，校准才要紧，比如[定阈值](/zh/notes/fraud-detection-practice/#threshold)。

**交叉验证有哪几种，各在什么时候用？** 各行独立时用 k 折。类别不平衡时用分层。多行属于同一实体时用分组。时间顺序要紧时用向前滚动。同一份数据既要调参又要估计表现时用嵌套。不管哪一种，缩放、编码和特征选择都要在每一折内部拟合。

**MAE、RMSE 还是 MAPE？** 均方根误差（RMSE）对大误差的权重更高，使它最小的是均值。平均绝对误差（MAE）更稳健，使它最小的是中位数。平均绝对百分比误差（MAPE）是相对误差，真值为零时没有定义，对高估和低估也不对称。我按大误差的代价来选。

**在同一个测试集上怎么比较两个模型？** 在同样的行上做配对比较。我对指标的差值做 bootstrap，按账户重抽样，看区间是否不包含零。AUC 还可以用 DeLong 检验。离线赢了之后，还要用[冠军–挑战者测试](/zh/notes/fraud-detection-practice/#drill-ztest)确认。

## 模型是怎么学习的 {#learning}

**偏差–方差的取舍是什么？** 期望平方误差可以拆成偏差的平方、方差和不可约的噪声。简单的模型偏差高，灵活的模型方差高。正则、更多数据和集成都是在这条取舍线上移动模型：bagging 降方差，boosting 降偏差。

**怎么看出过拟合，怎么办？** 训练误差低，验证误差高出很多。练习题里列了提升树的[控制手段](/zh/notes/fraud-detection-practice/#overfitting)，也有[教科书式的回答](/zh/notes/fraud-detection-practice/#classic-ml)。

**该加数据，还是换更好的模型？** 看学习曲线。如果数据增加时验证误差还在下降，加数据有用。如果训练误差和验证误差都高，是偏差问题，需要更好的特征或更大的模型容量。如果两者差距很大，是方差问题：加正则或加数据。

**什么是维度灾难？** 维度升高时，数据变得稀疏，最近邻和最远邻的距离几乎一样，覆盖整个空间所需的样本量按指数增长。最近邻、核方法和聚类受影响最大。办法是特征选择、降维，以及自带结构的模型。

**参数模型和非参数模型有什么区别？** 参数模型的参数个数固定，比如线性回归和逻辑回归。它效率高，但函数形式选错时有偏。非参数模型的复杂度随数据增长，比如最近邻、树和核方法。它灵活，但需要更多数据。

**生成模型和判别模型有什么区别？** 生成模型描述每个类别怎样产生特征，即 $P(x \mid y)\,P(y)$：朴素贝叶斯、高斯混合。判别模型直接描述 $P(y \mid x)$：逻辑回归、树、神经网络。数据足够时，判别模型通常更准。生成模型在数据少、特征缺失、基率改变时更从容。

**哪些模型需要特征缩放？** 凡是依赖距离、梯度下降或系数惩罚的模型：最近邻、k-means、支持向量机、主成分分析、带正则的线性模型和神经网络。树不需要，因为它按顺序分裂。

**类别特征怎么编码？** 类别少时用 one-hot。有顺序时，或者给树模型用时，用序数编码。类别很多时用 target encoding，要折外（out of fold）计算并向整体比率平滑，否则会泄漏标签。多到存不下时用哈希。神经网络里用学出来的 embedding。

**超参数怎么调？** 只有少数几个超参数要紧时，随机搜索比网格搜索好。每次拟合都很贵时，贝叶斯优化才划算。树的棵数或训练轮数用早停来定。我在验证数据上调参，时间顺序要紧时取更晚的时间段，测试数据只报告一次。大部分收益来自学习率、树的大小和正则强度。

## 经典算法 {#algorithms}

**决策树怎么选分裂点？** 选不纯度下降最多的那个。一个节点有 10 行，其中 4 个正样本，Gini 不纯度是 0.48。把它分成“4 行里 3 个正样本”和“6 行里 1 个正样本”两组，不纯度分别是 0.375 和 0.278，加权后是 0.317，所以增益是 0.163。树会试遍每个特征和每个切点，留下最好的。[下面的代码](#scratch)对单个特征做了这件事。

**随机森林为什么在每次分裂时随机抽特征？** 为了让树之间不那么相像。$B$ 棵树两两相关系数为 $\rho$ 时，平均值的方差是 $\rho\sigma^2 + (1-\rho)\sigma^2/B$。加树只能压低第二项，所以真正起作用的是降低 $\rho$。每个 bootstrap 样本没抽到的行，还能免费给出一个验证估计（out-of-bag）。

**梯度提升里的“梯度”是什么意思？** 每棵新树拟合的是损失对当前预测值的负梯度。平方误差下它就是残差，log loss 下是 $y - p$。学习率控制每一步走多远。练习题里[把它和 bagging 做了比较](/zh/notes/fraud-detection-practice/#trees)。

**XGBoost、LightGBM 和 CatBoost 怎么选？** XGBoost 用二阶信息和显式的正则，默认按层生长。LightGBM 把特征分箱成直方图，按叶生长，在大数据上最快，但要限制叶子数。CatBoost 用有序的目标统计量处理类别特征，用对称树，默认参数就很好用。

**解释一下支持向量机。** 它找间隔最宽的分隔超平面，只有落在间隔上或间隔内的点，也就是支持向量，决定这个平面。参数 C 在间隔宽度和违反间隔的程度之间取舍。核函数替换掉内积，不用真的算出展开后的特征，就能得到非线性边界。用径向基（RBF）核时，gamma 决定一个点的影响有多局部。特征必须缩放。训练开销随行数的增长快于线性，输出要经过校准才是概率。

**k 近邻是什么？** 用最近的 $k$ 个训练样本来预测。没有训练过程，预测很慢。$k$ 小则方差大，$k$ 大则偏差大。需要缩放，维度高时效果变差。

**朴素贝叶斯是什么？** 贝叶斯公式，加上“给定类别时各特征相互独立”的假设。它很快，数据少时和文本上都好用。它给出的概率过于极端，因为相关的证据被重复计算了；排序往往还不错。

**k-means、高斯混合和 DBSCAN 有什么区别？** k-means 把点分给最近的中心，再重新计算中心。它适合大小相近的球形簇，结果依赖初始点和尺度。高斯混合给出软分配和椭圆形的簇，用 EM 算法拟合；k-means 是它的极限情形。DBSCAN 从稠密区域向外长出簇，能找到任意形状并标出噪声点，但密度不均匀时效果不好。k 怎么选见[快问](/zh/notes/fraud-detection-practice/#classic-ml)。

**主成分分析做的是什么？** 找出方差最大的一组正交方向，也就是协方差矩阵的特征向量。保留前几个，特征值给出各自解释的方差。做之前先把特征标准化。它是线性的，主成分很难起名字，而且方差大不等于预测价值高。

**孤立森林怎么发现异常？** 它随机地切分数据。不寻常的点经过很少几次切分就被单独分出来，所以平均路径短就意味着异常。它不计算距离，扩展性好。练习题里讲了[它适合用在哪](/zh/notes/fraud-detection-practice/#anomaly)。

**什么是 stacking？** 用几个一级模型的预测值再训练一个二级模型。这些预测值必须来自一级模型没见过的那一折，否则二级模型学到的是过拟合的输入。收益通常不大，代价是线上部署和解释都更复杂。

**线性模型还是树？** 行数少、效应基本是可加的，或者需要外推、需要解释系数时，用线性模型。有交互、阈值效应、混合类型和缺失值时，用树。树无法预测超出训练数据范围的值。

## 神经网络 {#neural-networks}

**用一段话讲反向传播。** 前向传播算出损失。反向传播从输出到输入逐层应用链式法则，并复用中间结果，所以求出全部梯度的开销大约等于再做一次前向传播。然后优化器更新权重。

**隐藏层为什么用 ReLU 而不用 sigmoid？** sigmoid 和 tanh 在两端变平，梯度趋近于零，穿过很多层之后就消失了。ReLU 在输入为正时梯度是 1，计算也便宜。一个单元可能卡在零上不再更新，leaky ReLU 和 GELU 能避免这一点。

**梯度消失和梯度爆炸是怎么回事？** 穿过很多层或很多时间步的梯度，是许多项的乘积，所以会按指数缩小或放大。对策是 ReLU 一类的激活函数、合适的初始化、归一化和残差连接。梯度裁剪应对爆炸，门控单元应对循环网络。

**神经网络怎么做正则？** 权重衰减、dropout、早停、数据增强、把网络做小、label smoothing。dropout 在训练时随机把一部分激活置零，近似于对许多被“削薄”的网络取平均。

**卷积层擅长什么？** 它用小的滤波器在输入上滑动。权重共享加上局部连接，使参数量大大减少，而且同一个模式不管出现在哪里，响应都一样。池化和步长降低分辨率，扩大感受野。它适合图像；一维的卷积适合有局部模式的序列。

**RNN、LSTM 和 GRU 有什么区别？** 循环网络沿着序列传递一个隐藏状态，每一步用同一组权重，长距离的梯度会消失。LSTM 增加了一个细胞状态和输入门、遗忘门、输出门，信息和梯度可以保留很多步。GRU 把它们合并成两个门，参数更少。数据充足的地方，Transformer 已经取代了它们；序列短或需要流式处理时，循环模型仍然合适。self-attention 见练习题的[快问](/zh/notes/fraud-detection-practice/#deep-learning)。

**embedding 是做什么用的？** 给离散的对象（词、商户、设备）学一个稠密向量，让相似的对象离得近。类别很多时，它取代 one-hot 编码；可以和任务一起训练，也可以先训练好再交给树模型用。

**自编码器怎么发现异常？** 训练它通过一个很窄的中间层重构正常数据。和训练数据不像的点重构得差，重构误差就是异常分数。如果训练数据里混有异常，或者网络太大，它会连异常也学会重构。

**为什么在表格数据上树仍然强于神经网络？** [Grinsztajn 等人的基准测试](https://arxiv.org/abs/2207.08815)发现，在中等规模的表格数据集上树模型领先，并给出三个原因。表格数据的目标函数不平滑，而神经网络偏好平滑的函数。无信息的特征对神经网络的伤害更大。表格的每个特征各有含义，而具有旋转不变性的学习器会忽略这一点。输入有原始结构的地方，神经网络才占优：序列、文本、图像、图。

**batch size 和学习率有什么关系？** batch 越大，梯度噪声越小，可以承受更高的学习率；小 batch 的噪声本身有正则作用。常见的做法是先 warmup 再衰减。学习率是最要紧的超参数。

**cross-entropy、类别权重和 focal loss 有什么区别？** cross-entropy 就是分类问题的 log loss。类别权重把稀有类别的损失按比例放大。focal loss 给每一项乘上 $(1 - p_t)^\gamma$，压低容易样本的贡献。类别权重和 focal loss 都会扭曲概率，所以之后要重新校准。

**微调还是从头训练？** 预训练模型自带通用的特征，所以需要的数据和时间更少。可以冻结主干只训练输出头，可以用很小的学习率微调全部参数，也可以只训练小的适配器。风险是遗忘原来学到的东西，以及两个领域之间的差距。

## 强化学习 {#reinforcement-learning}

**什么是马尔可夫决策过程？** 状态、动作、转移概率、奖励和折扣因子。策略把状态映射到动作，目标是期望折扣回报最大。“马尔可夫”指下一个状态只取决于当前的状态和动作。

**基于价值的方法和基于策略的方法有什么区别？** 基于价值的方法，比如 Q-learning，学习每个状态下每个动作的价值，然后选最好的。它能很好地复用旧数据，适合离散动作。基于策略的方法，比如 PPO，沿着期望回报的梯度直接调整策略的参数。它能处理连续动作和随机策略，但方差更大。actor-critic 把两者结合起来：用学到的价值估计来降低策略梯度的方差。

**探索和利用怎么取舍？** 按当前最好的估计行动，现在就能拿到奖励；试别的动作，拿到的是信息。epsilon-greedy 随机探索。置信上界（UCB）给不确定性加一个奖励项。Thompson sampling 从后验里抽样，再按抽到的值行动。练习题里讨论了[它在欺诈里用在哪](/zh/notes/fraud-detection-practice/#bandits)。

**on-policy 和 off-policy 有什么区别？off-policy 评估为什么要紧？** on-policy 方法从当前策略产生的数据里学习。off-policy 方法可以从任何策略产生的数据里学习。在生产环境里，不能为了看看效果就把新策略直接上线，所以要用旧策略留下的日志来估计新策略的价值。重要性采样把每条日志里的奖励，按两个策略对所采取动作的概率之比重新加权。它需要日志里记录了动作概率，也需要两个策略有重叠；两者差别很大时，方差会很高。

**bandit 还是完整的强化学习？** bandit 里，一个动作只影响眼前的奖励。完整的强化学习里，动作还会改变下一个状态。长期影响很小或者无法衡量时，我从 bandit 做起。

**奖励设计难在哪里？** 奖励来得晚或来得少，就很难把功劳归给正确的动作。代理奖励会被钻空子：优化点击量不等于优化价值。训练之前我会先问一句：照这个奖励的写法，什么行为能把它最大化？

**用两句话讲 PPO。** 它是一种策略梯度方法，对新旧策略的概率之比做裁剪，这样同一批数据可以重复更新几次，策略也不会一下子走得太远。它简单、稳定，所以成了很多问题的默认选择。

## 标签不完整的数据 {#weak-labels}

**半监督学习和伪标签是什么？** 标签很少、无标签数据很多时：先用有标签的数据训练，再对其余数据做预测，把有把握的预测当作标签加进来，然后重训。风险是模型自己的错误被喂回去并且被强化。

**什么是 positive-unlabeled 学习？为什么欺诈符合这个设定？** 只有一部分正样本有标签，其余的是正负样本的混合。已确认的欺诈是正样本；“没有被报告”是无标签，不是负样本。如果有标签的正样本是全部正样本的随机抽样，那么用“有标签对无标签”训练出来的模型，给出的是真实概率乘以一个常数。排序保持不变，概率需要重新标定。

**什么是主动学习？** 选择给哪些样本打标签，通常选模型最没把握的那些。在欺诈里，人工审核队列就是打标签的预算，所以其中一部分应该给模型拿不准的案例，而不是只给分数最高的。

**什么是删失？它对近期的标签为什么要紧？** 到截止时间还没有发生的结果是右删失（right-censored）的：我只知道它“到现在还没发生”。把它算成负样本会低估比率。如果一半的欺诈在七天之内被报告，那么第七天观测到的 0.05%，最终大约会是 0.10%。生存分析用 Kaplan-Meier 曲线和风险模型，把这部分不完整的信息用对。

## 监控里的统计 {#monitoring-stats}

**KL 散度、Jensen-Shannon 散度和 PSI 是什么关系？** KL 散度是 $\sum p \log(p/q)$。它不对称；在 $q$ 为零而 $p$ 不为零的地方是无穷大。Jensen-Shannon 是它对称、有界的版本。分箱数据上的 PSI，是两个方向的 KL 散度之和。练习题里有[它的代码](/zh/notes/fraud-detection-practice/#psi)。

**计数类指标的报警阈值怎么定？** 给计数建模。如果每小时报警数服从均值为 100 的泊松分布，标准差是 10，出现 130 条以上的概率是 0.23%。真实的计数比泊松分布波动更大，还随时间有周期，所以我会和上周同一小时比较，并把界限放宽。

**为什么监控项一多，误报就多？** 这是多重检验。200 个指标各用一条三倍标准差的规则，在完全正常的一天里，至少有一个触发的概率是 42%。我会少设报警、把阈值设高，并要求异常持续一段时间才触发。

**怎么发现幅度小但持续的偏移？** 三倍标准差的规则发现不了它。累积和（CUSUM）或指数加权移动平均（EWMA）把小的偏差随时间累加起来，能更早触发。

### 用梯度下降拟合逻辑回归 {#code-logistic}

```python
import numpy as np

def fit_logistic(X, y, lr=0.5, steps=5000, l2=0.0):
    X, y = np.asarray(X, float), np.asarray(y, float)
    w, b = np.zeros(X.shape[1]), 0.0
    for _ in range(steps):
        p = 1 / (1 + np.exp(-(X @ w + b)))
        w -= lr * (X.T @ (p - y) / len(y) + l2 * w)   # gradient of the mean log loss
        b -= lr * np.mean(p - y)
    return w, b
```

平均 log loss 的梯度是 $X^\top(p - y)/n$，整个推导就是这一步。在 4,000 行模拟数据上，真实权重是 1.5 和 −1.0，截距是 −0.5；它返回 1.477、−1.033 和 −0.516，和 scikit-learn 的结果在小数点后三位一致。可以顺口说的几点：先把特征标准化，一个学习率才能适用于所有特征；L2 项不作用在截距上；真正的实现会在收敛时停止。

### 按 Gini 不纯度找最佳分裂点 {#code-gini}

```python
def gini(y):
    p = np.mean(y)
    return 2 * p * (1 - p)             # 1 - p^2 - (1 - p)^2 for two classes

def best_split(x, y):
    order = np.argsort(x)
    x, y = np.asarray(x)[order], np.asarray(y)[order]
    parent, best = gini(y), (None, 0.0)
    for i in range(1, len(x)):
        if x[i] == x[i - 1]:
            continue                    # no threshold separates equal values
        child = (i * gini(y[:i]) + (len(x) - i) * gini(y[i:])) / len(x)
        if parent - child > best[1]:
            best = ((x[i] + x[i - 1]) / 2, parent - child)
    return best
```

十个金额里有四笔欺诈，最佳阈值是 75，增益 0.309：阈值以上的每一行都是欺诈。这个版本在每个位置都重新计算不纯度，所以是平方复杂度。维护两侧正样本的累计数，排序之后就是线性的。

### K-means {#code-kmeans}

```python
def kmeans(X, k, n_iter=100, seed=0):
    rng = np.random.default_rng(seed)
    centers = X[rng.choice(len(X), k, replace=False)]
    for _ in range(n_iter):
        labels = np.argmin(((X[:, None, :] - centers[None, :, :]) ** 2).sum(axis=2), axis=1)
        new = np.array([X[labels == j].mean(axis=0) if (labels == j).any() else centers[j]
                        for j in range(k)])
        if np.allclose(new, centers):
            break
        centers = new
    inertia = float(((X - centers[labels]) ** 2).sum())
    return centers, labels, inertia
```

在三个模拟的簇上，它找回了三个中心，簇内平方和（返回值里的 `inertia`）和 scikit-learn 相同。每一步都只会让这个平方和变小，所以循环一定收敛，但收敛到的是依赖初始点的局部最优。实际使用时要多次初始化，或者用 k-means++。

### 区间和检验 {#code-stats}

```python
import math

def wilson_interval(k, n, z=1.959964):
    p = k / n
    centre = (p + z * z / (2 * n)) / (1 + z * z / n)
    half = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / (1 + z * z / n)
    return centre - half, centre + half

def bootstrap_interval(values, metric=np.mean, n_boot=2000, level=0.95, seed=0):
    rng = np.random.default_rng(seed)
    values = np.asarray(values)
    stats = [metric(values[rng.integers(0, len(values), len(values))]) for _ in range(n_boot)]
    lo, hi = np.quantile(stats, [(1 - level) / 2, (1 + level) / 2])
    return float(lo), float(hi)

def permutation_test(a, b, n_perm=10_000, seed=0):
    rng = np.random.default_rng(seed)
    a, b = np.asarray(a, float), np.asarray(b, float)
    observed = abs(a.mean() - b.mean())
    pooled = np.concatenate([a, b])
    hits = 0
    for _ in range(n_perm):
        rng.shuffle(pooled)
        hits += abs(pooled[:len(a)].mean() - pooled[len(a):].mean()) >= observed
    return (hits + 1) / (n_perm + 1)

def benjamini_hochberg(p_values, q=0.05):
    p = np.asarray(p_values, float)
    order = np.argsort(p)
    passed = p[order] <= q * np.arange(1, len(p) + 1) / len(p)
    k = passed.nonzero()[0].max() + 1 if passed.any() else 0   # largest rank that passes
    reject = np.zeros(len(p), dtype=bool)
    reject[order[:k]] = True
    return reject

def ks_statistic(a, b):
    a, b = np.sort(a), np.sort(b)
    grid = np.concatenate([a, b])
    cdf_a = np.searchsorted(a, grid, side="right") / len(a)
    cdf_b = np.searchsorted(b, grid, side="right") / len(b)
    return float(np.abs(cdf_a - cdf_b).max())
```

有两个细节常被问到。置换检验的 p 值在分子和分母上各加一，所以永远不会等于零。Benjamini-Hochberg 拒绝的是“通过的最大名次”之前的所有假设，包括其中没有通过各自阈值的那些。
